# Repository Guidelines & Workflow Rules

- **Automatic Commits**: Whenever you have implemented a feature, enhancement, or fix that updates the codebase, automatically commit the changes to `main` once verification succeeds.
- **Commit Message Format**: Include the summary of the user's prompt in either the commit summary (title) or description (body).
- **Remote Push**: Do not run `git push` automatically. Only push to GitHub when explicitly requested by the user.
